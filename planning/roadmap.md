# Provisional roadmap

**Exploratory, not an approved implementation specification.** Stages may be
revised, interleaved, or stopped when scientific evidence changes direction.

| Stage | Objective | Evidence needed before expanding scope |
| --- | --- | --- |
| 1. Repository and scientific foundations | Establish terminology, goals, documentation, package smoke checks, and Project Control discovery. | Inspectable workspace, clear limits, passing scaffold checks. This initialization addresses this stage only. |
| 2. Existing infrastructure assessment | Inspect reusable Cellerator/Baseplane capabilities and identify missing scientific/gradient operations. | Source-backed capability/gap assessment and a bounded consumer question. The initial ecosystem note is a starting point, not full qualification. |
| 3. Minimal generative experiment | Define one scientifically useful learned cellular-state transition problem. | Suitable data/provenance, explicit measurement/time assumptions, baselines, and reviewable validation criteria. No complete embryo is required. |
| 4. Architecture investigation | Compare conditional computation, MoE specialization, latent memory, recurrent/state-space or transformer mechanisms, and explicit operators. | Comparisons tied to the selected problem; justify complexity and preserve counterevidence. |
| 5. Initial training system | Train a small shared model and establish meaningful prediction and dynamical validation. | Reproducible held-out results, uncertainty and rollout checks; validated derivative/operator paths where used. |
| 6. Developmental generation | Extend to division, branching lineages, inheritance, environmental signaling, and interacting populations. | Lineage/population and perturbation evidence; stability and appropriate conservation/constraint checks. |
| 7. Cytoplast and FrameShift integration | Efficient shared-model execution and persistent interacting cell populations. | Verified numerical/lifecycle contracts, state and model-revision semantics, independent package operation, and externally allocated resources. |

Useful integration research may precede stage 7, but no speculative runtime
dependency or frozen interface should follow solely from this ordering.
