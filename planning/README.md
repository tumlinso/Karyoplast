# Planning

These are authored research proposals and decision records. They are not live
task state and do not approve implementing a model, running training, or using
GPUs. The initialization mandate covers documentation, packaging, tests, and
Project Control registration only.

- [Provisional roadmap](roadmap.md): possible stages and evidence needed to advance.
- [Open questions](open-questions.md): unresolved scientific and architectural choices.
- [Foundation decisions](decisions.md): choices actually made for this scaffold.

Project Control workspace and repository selectors are both `karyoplast`. See
[registration and discovery](../docs/project-control.md). Registration is
separate from initializing a Todo authority, importing a plan, or dispatching
work. If an authoritative plan is later adopted, use supported Project Control
preview/commit and workflow routes. Semantic Todo state is authoritative;
Markdown and snapshots are projections and must not be edited by hand.

Keep future research proposals in their own directories with question, scope,
assumptions, provenance, baselines, acceptance evidence, and unresolved choices.
Do not rewrite historical evidence to match a newer design.
