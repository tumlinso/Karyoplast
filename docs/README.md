# Documentation map

Karyoplast is a place to develop a scientific modeling program. These documents
organize intent and uncertainty without selecting a comprehensive framework.

| Document | Purpose |
| --- | --- |
| [Scientific vision](scientific-vision.md) | Autonomous cells, founder-to-population development, and limits of inference. |
| [Representational foundations](representations.md) | Numerical genome/state, observations, sequence grounding, and the metaphor's limits. |
| [Architectural exploration](architecture.md) | Competing mechanisms and scientific-operator/lifecycle boundaries. |
| [Training and evaluation](training-evaluation.md) | Candidate objectives, data requirements, branching dynamics, and scientific validation. |
| [Ecosystem assessment](ecosystem.md) | Directly inspected neighboring interfaces and prospective dependencies. |
| [Development](development.md) | Package checks, repository organization, and reproducible evidence. |
| [Project Control](project-control.md) | Registered workspace, useful orientation, discovery, and workflow authority. |

[Planning](../planning/README.md) separates a provisional roadmap, open questions,
and actual foundation decisions. Evidence records belong beside the claim they
support or in `docs/evidence/`, with source identities and explicit limits.
Implementation presence, execution success, numerical validation, predictive
validity, and mechanistic identification are distinct claims.
